# Thai Golden Bowl

One-page website for Thai Golden Bowl, a family-owned Thai restaurant in Finn Hill, Kirkland, WA.

Static HTML. No build step. Fonts and GSAP load from CDNs.

## Publish on GitHub Pages

1. Upload everything in this folder to the root of a GitHub repository.
2. In the repository, open Settings > Pages.
3. Under "Build and deployment", pick "Deploy from a branch", choose `main` and `/ (root)`, then Save.
4. The site goes live at `https://<username>.github.io/<repository>/` in a minute or two.

## Before launch

- Button links for online ordering, reservations, catering, private parties and specials still point to `#`.
- Opening hours, address, phone and the Google reviews link need to be confirmed with the client.
